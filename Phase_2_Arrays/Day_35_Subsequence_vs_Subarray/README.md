# 📖 Day 35: Subsequence vs Subarray

**Understanding difference, solving both types correctly.**

---

## Concepts

- Subarray: Contiguous elements
- Subsequence: Order preserved, not contiguous
- Substring: Special subarray (characters only)
- DP vs Greedy approaches

---

## Problems

| Problem | Difficulty | Key Concept |
|---------|-----------|------------|
| Longest Increasing Subseq | ⭐⭐ Medium | DP or binary search |
| Longest Increasing Subarray | ⭐ Easy | One pass |
| Increasing Triplet | ⭐⭐ Medium | Two pointers |
| Longest Common Subseq | ⭐⭐ Medium | DP 2D |
| Longest Common Subarray | ⭐⭐ Medium | Direct comparison |
| Is Subsequence | ⭐ Easy | Two pointer |

---

## Interview Readiness

✅ **Key Difference:** Contiguity changes complexity  
✅ **Tip:** Understand what constraints apply
