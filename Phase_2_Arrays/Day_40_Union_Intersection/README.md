# 📖 Day 40: Union & Intersection

**Set operations on arrays, deduplication, merging sets.**

---

## Concepts

- Array union (combine, deduplicate)
- Array intersection (common elements)
- Sorted vs unsorted approaches
- Hash vs two pointer

---

## Problems

| Problem | Difficulty | Key Concept |
|---------|-----------|------------|
| Intersection of Arrays | ⭐⭐ Medium | Two pointer or hash |
| Union of Arrays | ⭐⭐ Medium | Merge or hash |
| Common Elements K Arrays | ⭐⭐ Medium | Hash map count |
| Intersection Size 2 | ⭐⭐⭐ Hard | Greedy |
| Set Operations | ⭐ Easy | Hash set usage |
| Symmetric Difference | ⭐⭐ Medium | XOR logic |

---

## Interview Readiness

✅ **Technique:** Know hash vs two pointer trade-offs  
✅ **Follow-up:** What if arrays are sorted? Very large?
