## Key Insights

1. **Coordinate System:** Top-left is (0,0), grow right and down
2. **Rotation Tricks:** Transpose + reverse for 90° rotation
3. **Layer Concept:** Process matrix in concentric layers
4. **In-place:** Often possible with smart indexing
