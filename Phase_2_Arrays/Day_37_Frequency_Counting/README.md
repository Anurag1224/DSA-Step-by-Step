# 📖 Day 37: Frequency & Counting

**Hash map based solutions, frequency patterns, counting problems.**

---

## Concepts

- Hash map frequency tracking
- Most/least frequent elements
- Anagram detection
- Duplicate detection

---

## Problems

| Problem | Difficulty | Key Concept |
|---------|-----------|------------|
| Top K Frequent | ⭐⭐ Medium | Heap or bucket sort |
| K Frequent Pairs | ⭐⭐⭐ Hard | Multi-key frequency |
| Valid Anagram | ⭐ Easy | Frequency comparison |
| Group Anagrams | ⭐⭐ Medium | Sorted key grouping |
| Find All Duplicates | ⭐⭐ Medium | Marking technique |
| Missing Number | ⭐ Easy | XOR or sum |

---

## Interview Readiness

✅ **Pattern:** Hash map solves most frequency problems  
✅ **Optimization:** Avoid hash map when possible (array marking)
