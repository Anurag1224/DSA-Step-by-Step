## Concepts

- Sum methods
- Frequency counting
- Marking technique

## Problems

| Problem | Difficulty | Key Concept |
|---------|-----------|------------|
| Find Missing Number | ⭐ Easy | XOR or sum |
| Find Duplicate | ⭐ Easy | Marking or hash |
