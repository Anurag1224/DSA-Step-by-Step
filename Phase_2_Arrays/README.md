# 🟢 PHASE 2: Arrays (Most Asked in FAANG)

**Master data structure fundamentals and optimization techniques.**

---

## Why PHASE 2 Matters

Arrays are the **foundation of all data structures**. In this phase, you'll learn:
- When and how to optimize beyond brute force
- Two-pointer technique (interview favorite)
- Sliding window pattern (solves 30% of array problems)
- Prefix sum tricks (dynamic range queries)
- How to think about space-time tradeoffs

This phase is where optimization becomes **natural, not forced**.

---

## How to Approach PHASE 2

1. **Understand the problem first** — What are we optimizing?
2. **Brute force first** — Simple solution, measure complexity
3. **Identify the pattern** — Two pointers? Sliding window? Prefix sum?
4. **Apply the technique** — Once pattern is clear
5. **Test edge cases** — Empty array, single element, duplicates
6. **Commit regularly** — Daily commits with meaningful messages
