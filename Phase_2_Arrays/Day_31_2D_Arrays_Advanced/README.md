## Key Insights

1. **Rotated Search:** Find rotation point with binary search
2. **Row-Col Sorted:** Start from corner (top-right or bottom-left)
3. **DP Approach:** Build on previous results
4. **Graph Traversal:** Matrix as implicit graph
