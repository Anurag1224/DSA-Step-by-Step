## 💡 Interview Takeaway

When asked pattern problems in interviews:

1. **Draw the pattern first** — on paper or verbally
2. **Identify the structure** — rows and columns
3. **Find the formula** — what changes per iteration
4. **Code incrementally** — solve base case first
5. **Test edge cases** — n=1, n=2, boundaries
6. **Optimize if asked** — but correctness first
