## Capstone Projects

### Project 1: Pattern Menu System

**Objective**: Create a program where user selects pattern type

```
Menu:
1. Triangle
2. Pyramid
3. Diamond
4. Floyd's Triangle
5. Custom

Choice: 3
Size: 4
```

**Skills Tested:**
- Function organization
- Parameter handling
- User input
- Multiple pattern types

### Project 2: Pattern Validator

**Objective**: Verify if user-provided pattern is correct

**Input**: Pattern as text
**Output**: "VALID" or "INVALID"

**Skills Tested:**
- Pattern recognition
- Verification logic
- String handling

### Project 3: Combined Patterns

**Objective**: Create patterns combining multiple shapes

Example:
```
  *       *
 * *     * *
* * *   * * *
 * *     * *
  *       *
```

**Skills Tested:**
- Layout management
- Spacing precision
- Multiple components

### Project 4: Pattern Transformer

**Objective**: Transform one pattern into another

Example:
- Input: Triangle of size 4
- Transform: Make it hollow
- Output: Hollow triangle

**Skills Tested:**
- State transformation
- Conditional logic
- Algorithm application

### Project 5: Creative Challenge

**Objective**: Design your own pattern!

Requirements:
- Scalable (works for n=1,2,3,...)
- Meaningful (not random)
- Documented (explain logic)
- Tested (verify edge cases)

**Skills Tested:**
- Creativity
- Problem-solving
- Communication
- Testing mindset
