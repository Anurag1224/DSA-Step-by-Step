# 📝 Day 7 Notes: Mindset & Checklist

## Quick Summary

Today is about thinking before typing. The code is only as good as the plan behind it.

### Key lessons
- Dry run every example before coding
- Turn requirements into sample inputs
- Check edge cases before implementation
- Use a checklist for every problem
- Commit with a clear message after each day

---

## Problem-Solving Checklist

1. Read the full problem carefully
2. Identify input and output clearly
3. Write at least one normal example
4. Write edge cases (empty, smallest, invalid)
5. Dry run the example manually
6. Write code based on the dry run
7. Test with the examples and edge cases

---

## Common Mistakes

- Coding immediately without understanding
- Assuming edge cases are not important
- Forgetting invalid or empty input
- Not tracing the algorithm step by step
- Skipping the final validation before submit

---

## Dry Run Example

Problem: Check if the array `[3, 1, 4]` contains the target `4`.

Manual trace:
- Check `3` → not target
- Check `1` → not target
- Check `4` → found at index 2

If this matches your code, your logic is correct.
